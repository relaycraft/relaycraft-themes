# RelayCraft Themes 🎨

Official theme registry for **RelayCraft**, the next-generation AI-powered HTTP client.

This repository hosts the manifest (`themes.json`) and source code for community and official themes.

## 📦 Installation

### Option 1: In-App Market (Recommended)
1. Open **RelayCraft**.
2. Go to **Settings** -> **Appearance**.
3. Click **Browse Market**.
4. Find a theme you like and click **Install**.

### Option 2: Manual Installation (.rctheme)
1. Download a theme package (e.g., `neon-dark.rctheme`) from the [Releases](https://github.com/relaycraft/relaycraft-themes/releases) or source.
2. In **Settings** -> **Plugins/Themes** (or Appearance), click **Install from File**.
3. Select the `.rctheme` or `.zip` file.

## 📂 Repository Structure

- `themes.json`: The central registry file used by RelayCraft to discover themes.
- `themes/`: Source directories for each theme.
  - `theme-name/theme.yaml`: Metadata and color definitions.
  - `theme-name/styles.css`: (Optional) Advanced CSS overrides.
  - `theme-name/assets/`: (Optional) Local assets like fonts or background images.
